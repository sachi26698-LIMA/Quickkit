# QUICKKIT Brand Guidelines

**Status: official and permanent.** This document is the single source of
truth for the QUICKKIT brand system. Before creating any new page, tool,
feature, email template or promotional asset, consult this file. Never
introduce an unrelated logo, a different brand spelling, a random colour
palette or an inconsistent tagline.

Reference artwork used to establish this identity is preserved at
[`docs/brand/reference/`](brand/reference/) and must not be overwritten.

---

## 1. Official name and tagline

| Element | Value |
| --- | --- |
| Brand name | **QUICKKIT** |
| Official tagline | **Small tasks. Quick solutions.** |

The official spelling is always **QUICKKIT** — one word, all capitals in the
visual identity. Never use *Quick Kit*, *Quickkit*, *Quick-Kit* or any other
variant in the visual brand identity (logos, wordmarks, headings, app icons,
email headers, social cards). Mixed-case `QuickKit` exists only as a
machine-readable search alias in JSON-LD (`alternateName`), never as visible
brand text.

The tagline is always exactly **“Small tasks. Quick solutions.”** — two
sentences, each ending with a full stop. Legacy taglines (“Handy tools. Zero
hassle.” and similar) are retired and must not reappear.

### Brand personality

Premium · Futuristic · Innovative · Fast and reliable · Friendly and
accessible · Modern technology ecosystem.

## 2. Logo system

The identity has two primary assets that may stand alone or combine:

1. **Symbol** — the orbital mark: a gradient orbital ring (the “Q”), a dark
   planet disc with a star-speckle surface, a lightning bolt at the centre,
   a Saturn-style orbit ring crossing in front, a Q-tail at the lower right
   and three sparkle stars at the upper right. This is a distinctive orbital
   identity — never substitute a generic lightning icon.
2. **Wordmark** — **QUICKKIT** in heavy italic geometric sans (vector
   letterforms, Montserrat Black Italic outlines). *QUICK* is Deep Purple →
   Royal Violet; *KIT* is Hot Pink → Magenta. Below it sits the tagline in
   elegant italic Deep Purple with a purple-to-pink crescent swoosh.

### Lockup variants

| Variant | Construction |
| --- | --- |
| Primary symbol | Full-colour symbol alone |
| Wordmark | QUICKKIT wordmark + tagline + swoosh |
| Horizontal combination | Symbol left, wordmark block right, vertically centred |
| Vertical combination | Symbol top, wordmark block below, horizontally centred |
| White | Full lockup, 100% white, one ink (bolt knocked out of the disc) |
| Dark | Full lockup, Dark Navy `#17132F`, one ink |
| Monochrome | Full lockup, pure black, one ink (strict single-ink reproduction) |
| Monochrome white | Full lockup, pure white, one ink |

Approved constructions are generated by `scripts/brand/generate-assets.mjs`.
Rebuild assets through the generator; never freehand-redraw the art.

### Supporting colours

| Name | Hex | Use |
| --- | --- | --- |
| Dark Navy | `#17132F` | Dark backgrounds, body ink, dark logo |
| White | `#FFFFFF` | Light backgrounds, reversed logo |
| Light Background | `#FAF8FF` | Default app/page background |
| Soft Lavender | `#F0E8FF` | Tinted surfaces, borders, skeletons |

### Text-safe derivatives

Pure brand colours are for fills, gradients and graphics. When a brand hue
must carry body text on a light background, darken it only as far as WCAG AA
requires (≥ 4.5:1):

| Name | Hex | Derived from |
| --- | --- | --- |
| Hot Pink · text | `#B31277` | Hot Pink `#F018A8` |
| Deep Purple · shade | `#241148` | Deep Purple `#30105F` (hover/deepest states) |

### Semantic colours (not brand)

Alert coral `#FF6B6B` / `#C93A3A` is reserved for errors and warnings so that
warnings never read as decoration. It is not part of the brand palette and
must not be used as an accent.

### Gradients

| Token (CSS) | Stops | Use |
| --- | --- | --- |
| `--brand-gradient-wordmark` | `#30105F → #6420C8` | QUICK letters |
| `--brand-gradient-kit` | `#F018A8 → #D600E8` | KIT letters |
| `--brand-gradient-symbol` | `#F018A8 → #8B20F5 → #08C9F2` | Symbol ring |
| `--gradient-primary` | `#241148 → #30105F → #6420C8` | UI hero/CTA gradients |

Use gradients carefully. Avoid excessive glow, visual clutter and inconsistent
colours. The canonical palette is defined once in `app/globals.css` (the
`--brand-*` tokens) and in `scripts/brand/generate-assets.mjs` (`PALETTE`).

## 4. Typography

| Role | Typeface | Treatment |
| --- | --- | --- |
| Wordmark | Montserrat Black Italic (vector outlines in the SVG assets) | Heavy italic display |
| Headings | Geist (`--font-display`, system sans fallbacks) | Geometric sans, tight tracking |
| Body | Geist (`--font-body`, system sans fallbacks) | Highly readable sans |
| Buttons | Geist / system sans | Semibold (600) |
| Tagline | Montserrat Medium Italic (vector in SVG assets; italic fallback in HTML) | Elegant italic |

The wordmark and tagline ship as vector outlines inside the logo SVGs, so
they render identically everywhere without loading a web font. Where the
tagline must appear as live text (emails, plain-HTML contexts), set it in
italic with the `--font-wordmark` stack (`"Montserrat", "Arial Black",
"Segoe UI", sans-serif`) or a clean system italic.

## 5. Spacing, sizing and clear space

- **Clear space:** keep free space around every logo equal to at least half
  the symbol’s height (½ × H) on all sides. Nothing — type, rules, edges —
  may enter this zone.
- **Minimum sizes:** symbol 24 px; horizontal lockup 120 px wide; wordmark
  alone 90 px wide. Below these, use the symbol alone (it stays recognisable
  down to a 16 px favicon).
- **Alignment:** in the horizontal lockup the symbol and wordmark block are
  vertically centred with a gap of ≈ 0.15 × symbol height. In the vertical
  lockup the symbol sits above the wordmark block, both centred.

## 6. Background usage

| Background | Approved logo |
| --- | --- |
| White / Light Background / Soft Lavender | Primary colour lockup, or Dark / Monochrome |
| Dark Navy / dark photography | White (or Monochrome White) |
| Busy photography | White or Dark one-ink only, on a solid scrim if contrast fails |
| Brand gradient surfaces | White one-ink lockup |

Contrast must pass WCAG AA for text near the logo; the one-ink variants exist
exactly for the cases where colour art would lose contrast.

## 7. Correct and incorrect usage

**Do**

- Use the shipped SVG/PNG assets from `public/brand/` (or the inline React
  components in `components/brand-logo.tsx`).
- Keep the QUICK/KIT colour split and gradient directions.
- Use the tagline exactly as specified.
- Recolour only via the approved white / dark / monochrome variants.

**Do not**

- Do not respell the name (Quick Kit, Quickkit, QUICK KIT …).
- Do not rotate, skew, stretch, outline, add shadows to, or recolour the logo.
- Do not rebuild the wordmark from live fonts in production assets.
- Do not replace the orbital symbol with a generic lightning bolt.
- Do not place the colour logo on a background it fails against — switch to a
  one-ink variant.
- Do not use retired taglines or legacy palettes (plum `#54205F`, rose
  `#F04F9B`, coral brand accents, `#FDF7F5` backgrounds).

`components/brand-logo.tsx` (`BrandSymbol`, `BrandWordmark`,
`BrandWordmarkFull`) — these are generated from the same artwork, so the site
chrome can never drift from the shipped files.

## 9. Governance

This identity is QUICKKIT’s official brand system for all future development.
Any new surface (page, tool, email, ad, social card, PWA asset) must follow
this document. When extending the system, update this file first, regenerate
assets with `scripts/brand/generate-assets.mjs`, and record every file in
`docs/BRAND_ASSET_INVENTORY.md`.
