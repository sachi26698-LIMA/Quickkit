## 1. Browser installation — exact limitation

**What failed:**

```
$ npx playwright install chromium
Downloading Chrome for Testing 156.0.8078.4 … from https://cdn.playwright.dev/…
Error: Client network socket disconnected before secure TLS connection was established
  code: 'ECONNRESET', host: 'cdn.playwright.dev', port: 443
```

The sandbox allows outbound traffic only to `github.com`, `codeload.github.com`, `api.github.com`, `registry.npmjs.org`, `pypi.org`, `files.pythonhosted.org`. The Playwright CDN (`cdn.playwright.dev`) is not among them, and no system Chrome/Chromium/Firefox/WebKit binary exists on the image (`find / -name chrome …` → nothing).

**Workaround used (all artifacts from the allowed npm registry):**

```bash
# 1) Chromium build shipped inside an npm tarball (no CDN needed)
mkdir -p /tmp/qa-tools && cd /tmp/qa-tools && npm init -y
npm install @sparticuz/chromium@153
node -e "require('@sparticuz/chromium').default.executablePath().then(console.log)"
#    -> /tmp/chromium   (Chromium 153.0.8010.0)

# 2) Extract its bundled runtime libs (libnss3/libnspr4…)
node -e "const z=require('zlib'),f=require('fs');\
f.createReadStream('node_modules/@sparticuz/chromium/bin/al2023.tar.br')\
 .pipe(z.createBrotliDecompress())\
 .pipe(f.createWriteStream('/tmp/al2023.tar'))\
 .on('finish',()=>console.log('ok'))"
mkdir -p /tmp/al2023 && tar -xf /tmp/al2023.tar -C /tmp/al2023

# 3) Run E2E — playwright.config.ts already honors this env var
cd /home/user/Quickkit
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/tmp/chromium \
LD_LIBRARY_PATH=/tmp/al2023/lib \
npx playwright test --project=chromium
```

**Normal local environment (no workaround needed):**

```bash

npx playwright install --with-deps chromium   # or: npx playwright install --with-deps
npm run build
```
