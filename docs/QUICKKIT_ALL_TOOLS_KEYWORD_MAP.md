## How to read this map

Each tool gets one table row per keyword group. The **primary** keyword owns the page;
**secondary** keywords are rendered in the registry record; every remaining group is
written into the page's copy, headings, FAQs and internal-link anchors as natural
prose. None of them appear as a visible keyword list.

| Group            | What it covers                                                   |
| ---------------- | ---------------------------------------------------------------- |
| Primary          | The one short-tail phrase the page is built around               |
| Secondary        | The five registry keywords the audit checks                      |
| Alternative name | What else users call this tool                                   |
| Synonym          | Equivalent phrasings of the same task                            |
| Action           | What the user is trying to do                                    |
| Long-tail        | Specific, multi-word variations                                  |
| Problem          | The situation that sent them searching                           |
| Question         | Natural-language questions                                       |
| Qualifier        | Free / online / browser / no-signup framings, where true         |
| India            | Indian English, Hindi and Hinglish phrasings, only where genuine |
