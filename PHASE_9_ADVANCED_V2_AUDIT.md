## Shared UI, catalog, and test audit

- `app/tools/[calculator]/page.tsx` maps existing routes to components; `ToolShell` retains breadcrumbs, related calculators and layout. `components/tools/phase9-shared.tsx` and `components/tools/calculator.tsx` offer differing session-only history implementations. Input data is processed locally; introducing external services requires explicit privacy review.
- `app/category/[slug]/page.tsx` gets counts from `toolsByCategory` in `lib/catalog.ts` and preserves the grid/navigation, but calculator-category search/filtering is absent. `components/tool-explorer.tsx` provides separate search on `/tools`. Recommendations are chosen by `ToolShell`.
- `app/globals.css` is light-themed and provides shared responsive layouts and visible focus states, using purple/lavender tokens rather than the requested palette. A visual refresh needs contrast and regression checks; no attached reference screenshots were available in this message. Existing genuine captures are in `docs/phase-9-v2-final-evidence/`.
- Existing CI previously reported 367 passed, 4 skipped, and two WebKit PDF-merger failures (filename and color contrast). Earlier local Chromium result of 319 tests predates this audit; none of those tests has been rerun on this new branch. Browser/assistive technology coverage is incomplete.

## External dependency blocker — live currency rates

No exchange-rate provider, feed URL, freshness/SLA contract, or access arrangement is configured in the repository. This environment's outbound host allowlist does not include a live exchange-rate API. The existing discount currency selector only changes formatting and is **not** currency conversion. A reliable live conversion feature cannot be implemented or verified here without an approved accessible source and timestamp/failure policy. The owner has approved deferring currency conversion while other upgrades proceed. Do not insert hardcoded rates or market them as live. IANA timezone work can be local via `Intl` and does not itself require such an API, subject to runtime timezone data and DST tests.

## Continuation after the blocker is resolved

1. Establish an approved, accessible exchange-rate provider and privacy/cache/freshness policy; do not collect credentials in chat. If currency conversion is explicitly deferred, continue the other work without presenting currency conversion as live.
2. Fix BMI age gating first, with unknown/minor cases, adult thresholds and history restore tests.
3. Implement remaining capabilities in small batches, preserving existing routes, tests, formats, disclosures and session-only privacy model.
4. Expand independent formula/edge/browser/accessibility tests; run unit, integration, Chromium, lint, TypeScript, formatting and build; report cross-browser limitations and actual previews.
5. Update the per-feature matrix and `TOOL_DEVELOPMENT_STATUS.md` throughout. Do not merge or deploy without approval.
